# Análise de Dados com SQL | Alura

## Sobre o projeto

Projeto de análise exploratória de dados desenvolvido
a partir dos estudos de SQL na Alura.

O objetivo é analisar dados comerciais utilizando
consultas SQL, agregações e indicadores de desempenho.

## Tecnologias

- SQL
- SQLite
- Python (testes e automação)
- VS Code
- Git e GitHub

## Análises

1. Consultas básicas e manipulação de datas
2. Desempenho dos fornecedores
3. Participação das categorias
4. Análise da Black Friday
5. Indicadores e métricas de vendas

## Técnicas SQL

- SELECT e WHERE
- GROUP BY e ORDER BY
- JOIN
- COUNT, SUM e AVG
- CASE WHEN
- Subconsultas
- Common Table Expressions (CTEs)
- strftime
- Cálculo de porcentagens

## Melhorias planejadas

- Revisão das consultas SQL
- Testes automatizados
- Relatórios analíticos
- Comparação de desempenho entre anos
- Visualização de indicadores
- Documentação dos resultados reais

## Banco de dados

O banco de vendas será incorporado após
a exportação e verificação dos dados e
das permissões de redistribuição.

## Origem

Estudos realizados na plataforma Alura.

As análises, melhorias e documentação
serão desenvolvidas e ampliadas neste projeto.
